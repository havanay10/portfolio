# Portfolio — Arnot Raharison

Portfolio personnel présentant mon parcours, mes compétences et mes projets
en tant qu'étudiant en informatique et développeur web.

## Aperçu

- **Hero** : présentation et accroche
- **À propos** : parcours et objectifs
- **Compétences** : technologies maîtrisées
- **Projets** : réalisations concrètes avec liens et captures
- **Contact** : moyens de me joindre

## Stack technique

- **React 18** + **TypeScript**
- **Vite** (bundler et dev server)
- **CSS Modules** (styles par composant)
- **Google Fonts** (Inter)

## Installation

```bash
# Cloner le dépôt
git clone https://github.com/havanay10/portfolio.git
cd portfolio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
